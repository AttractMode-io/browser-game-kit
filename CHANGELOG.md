# Changelog

## 0.4.0 - 2026-10-26 (release candidate)

- Added typed browser/headless achievement clients, account-isolated bounded retries, accepted/pending/rejected results, original event timestamps and an optional silent accessible panel.
- Added a deterministic schema-v1 rule engine, positive/negative/replay fixtures, local simulation and an explicitly configured connected sample using the existing game backend session.
- Added CLI validation, diff, simulation, export and scoped remote draft/publication/build binding. Remote commands preview by default; execution requires a short-lived Studio authoring grant and exact project/environment confirmation.
- Added four project-local achievement/progression skills, safe installer selection, complete TypeScript declarations, migration guidance and two new read-only MCP documents. Bundled documentation MCP is 1.1.0; its three tools remain read-only.
- Preserved legacy definitions.put, saves and progression adapters. No automatic award import, XP transfer or email-based career merge. Optional profile linking requires authenticated game proof and explicit central account consent.
- Hosted versioned-set access remains an approved browser pilot: matching platform migrations/service, default-off global and project enablement, approved registration and scoped server credentials are required. Local verification is not an independent developer onboarding or hosted deployment claim.
- No React Native adapter, global XP/ranking, automatic public sharing or independent anti-cheat certification. Released v0.3.4 remains unchanged.

## 0.3.4 - 2026-10-24

- Updated the optional documentation MCP to SDK 1.32.2 and Zod 4.6.7, with patched transitive dependencies.
- Verified protocol negotiation, tool schemas and the fixed read-only documentation boundary against the updated dependencies.
- Added the M8ven publisher-verification badge. The MCP remains local stdio only; no remote gateway or additional permissions were added.

## 0.3.3 - 2026-10-07

- Clarified the operator-managed playtest path for listed external games: approved request, independent ownership verification and separate agreed session terms.
- Kept tester and payout information private and distinguished campaign drafts from open recruitment.
- Synchronized installed coding-agent guidance with the developer onboarding guide.
- Documentation-only update; no new API permissions, payment features or automatic tester recruitment.

## 0.3.0 Progression early access

- Added private-session progression bridge, server-only scoped transport, revisioned save client and explicit conflict handling.
- Added game XP, achievements, history and provenance-separated leaderboard client methods and accessible UI components.
- Added persistent single-host puzzle validation with atomic event/outbox storage, restart recovery and retry acknowledgement.
- Added progression integration documentation and read-only MCP discovery.
- Requires matching platform migrations, reviewed enablement and separately issued scoped credentials. Available only to approved integrations with scoped credentials; external hosted pilot remains outstanding.
- No global reputation, payment or competitive reward is inferred from browser assertions.

## 0.2.0 Stage 1 foundation

- Added encrypted durable single-host sessions and a human local consent UI.
- Breaking: connected configuration now requires expected game ID and a persistent player-ID key; see docs/migration-0.2.md.
- Added reproducible isolated local Supabase OAuth protocol tests with disposable identities.
- Added real locally bundled Three.js scene and active-registration enforcement with scoped player IDs.
- Added redacted local/optional public-connectivity doctor with explicit registration checks.
- Added browser/server package boundaries and session lookup cancellation/timeouts.
- Added extracted ZIP smoke checks and documentation MCP guides.
- Connected mode rejects unsupported environments; offline simulation is not a hosted sandbox.

## 0.1.2 - 2026-10-05

## 0.1.1 - 2026-10-01

## 0.1.0 · September 29, 2026

Initial standalone public release.

- Playable offline browser game and signed simulated OIDC login.
- Backend account adapter and registered-client development path.
- Codex, Claude Code, Cursor and Gemini project skills.
- Optional read-only local MCP for documentation and capabilities.
- Security tests, registration checklist and deployment guidance.

Live client registration is reviewed separately. Achievements, shared XP, payments and cloud saves are not third-party APIs in this release.
